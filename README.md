# StudyLogger

## 概要
資格学習などの学習内容をExcelに自動出力するアプリケーションです。

## ダウンロード
[⬇️ StudyLoggerをダウンロード](https://github.com/Yzumi158pri/StudyLogs/releases/latest/download/StudyLogger_Installer.zip)

[⬇️ 操作方法はこちら](https://github.com/Yzumi158pri/StudyLogs/releases/latest/download/StudyLogger_Manual.xlsx)

## 必要環境

このアプリを使用するには、以下のランタイムが必要です。

- .NET 10 Desktop Runtime
- Windows x64

.NET Desktop RuntimeはMicrosoft公式サイトから
ダウンロードしてインストールしてください。

インストール後、本アプリを起動してください。
